# Lumenforge

An incremental game of light, inspired by *Antimatter Dimensions* and *Cookie Clicker*.
Kindle the last star in a dead universe, go Supernova, chart Constellations, endure Trials,
run a Fusion Reactor, Collapse into a Black Hole — and fill the universe with Infinite Light.

**Play:** https://obsidianarmor1.github.io/lumenforge/

Plain HTML, CSS and vanilla JavaScript — no libraries. Autosaves to localStorage, with import/export.

- `index.html`, `css/`, `js/` — the game
- `sim/` — Node balance simulator used for tuning (`node sim/sim.js 8 hearth 1`)
- `Planning.md` — design document and balance notes
